## Proxmox VE 8.4

A homelab virtualization server built using Proxmox VE 8.4, hosted on repurposed hardware. Used as a learning platform to experiment with containerization, virtual networking, automation, and DevOps workflows in a real-world environment.

### Features

- Hosted multiple virtual machines and LXC containers for isolated development and testing environments
- Deployed web applications including a capstone website using Nginx and Gunicorn
- Configured reverse proxy, firewall rules, and basic TLS with Let's Encrypt
- Created custom secure remote desktop environments using Kasm Workspaces
- Automated container provisioning using Ansible playbooks

### Skills & Concepts

- Virtualization, containerization, and resource allocation
- Networking fundamentals (bridging, NAT, DNS, DHCP)
- Server administration and CLI-based system management
- Configuration management with Ansible
- System troubleshooting and log analysis
- Security practices for self-hosted services
