## Kasm Workspaces

A self-hosted containerized desktop environment solution deployed within my Proxmox lab. Kasm Workspaces provides browser-based access to secure, ephemeral containers for development, testing, and remote access scenarios. Built to support personal DevOps workflows and reduce risk while working with unfamiliar tools or code.

### Features

- Secure, containerized desktop sessions accessible through a web browser  
- Custom workspace images tailored for development and troubleshooting  
- Ephemeral environments that reset on session end, improving security  
- Integrated user authentication and access control  
- Easily integrated with reverse proxy for SSL and remote access  
- Low-resource consumption compared to traditional virtual machines  
- Self hosted but accessable via a publicly accessable domain! 
  - Ask me to create a new user so you can try it out!

### Skills & Concepts

- Container-based virtualization and ephemeral session design  
- Docker image customization and container lifecycle management  
- Remote desktop protocol alternatives via web-based UI  
- Network security and reverse proxy configuration (TLS, firewall rules)  
- User access control and basic identity management  
- Browser sandboxing and isolation principles for safe experimentation
